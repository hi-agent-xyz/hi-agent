# 活儿在你忙着别的事的时候干完了(它照样送到你手上)

**Persona:** 老板(用户)。半小时前随口要了一件有交付物的活(一个 view),之后话题转到别处,而且那件别的事**正不顺**——他在追一个没修好的 bug,语气已经急了。他**没有**在想着那个 view;他默认要过的东西自己会来。
**Goal:** 拿到自己要过的东西,而不需要记得回头再问一次。
**Preconditions:** hi-agent 在跑;一件会产出交付物的活已经派出去,worker 正在做;对话此后转到另一个更热的话题。

> 本 journey 提炼自 2026-08-18 的真实片段:老板 13:43 要"返川行程 view",worker 14:25 做完并改对了最后一版,而这件事**从头到尾没有被送到人手上**——直到 22 分钟后老板自己发现。整个链路上**没有任何一环报错**:worker 交了,Cognition 收了,Reaction 收了,ledger 写了 `done`。完整证据见 [gaps.md#29](gaps.md)。
>
> 它与 [25](25-resume-interrupted-work.md) 是**孪生但不同的一类**:25 恢复的是**被重启打断**的半成品;这里的活**干完了、干对了**,只是**没送到**。25 的敌人是进程死掉,这里的敌人是**注意力**——人的、以及 agent 自己的。

## Expected outcome

- 老板**不需要记得**回头问;要过的东西自己会到,哪怕中间隔着一场别的争论。
- 送到的形式是**屏幕上出现那个 view**,伴随一句人话;不是一个让人自己去开的 ref。
- 如果此刻确实不该打断,他会**知道什么时候给**——而不是什么都没有。
- 那条 task 在**人看见之后**才关;在此之前它一直在,并且每一轮都还在眼前。

## UX principles this journey establishes

- **交付 = 到人眼前。** 产出存在、报告写了、ledger 盖了章,三件事加起来也不等于交付。整条链路上每个环节都可以"成功"而人什么都没拿到,而且这种失败**不报错**。
- **worker 的 "delivered" 是"交到你手上"。** 上一环收到东西就当人拿到了,是同一个词的两个意思在链路上滑了一格。
- **关账要有一个自己写不出来的依据。** Cognition 坐在对话之外,发出去的都是提议、声音可以不采纳、没有回执——所以它判断交付与否时**天生是瞎的**。给它"屏幕上出现过什么",不是加一道闸,是**补上它拿不到的那个事实**;判断权一点没动。
- **压着好消息是一个有期限的决定。** 现场正热时先不打断是对的;没有期限的"先放着"和忘了在事后分不出来。
- **多件事一条消息时,人在等的那件先说。** 剪裁是给细节用的;一件人已经等了半小时的成品不是细节,而且它恰恰是**最容易被剪掉**的那件——因为最近这一分钟的对话不是关于它的。
- **兜底是重说,不是拦截。** 每轮都在的投影,胜过一道可以忘记装的闸——尤其当那道闸忘了装的时候是**静悄悄**的,和一切正常长得一模一样。

## Edge cases & failure modes

- **老板中途明确说"这个先不急"** → 那是**改了优先级**,不是取消:task 转 `todo` 并记下他的原话,不是 `done`([`arch/data.md`](../arch/data.md))。
- **交付物不是 view**(一个文件、一次外部动作)→ `## On their screen` 帮不上忙,这一路目前**只有引导没有事实**。已知边界,见 [gaps.md#29](gaps.md) 的"没盖住的地方"。
- **同一个 ref 反复覆盖**(rough → 精修)→ 第一次上屏就算送到;之后的精修是同一个地方变好,不是一件新的欠账([20](20-reuse-built-views.md))。
- **人当时不在**(空房间)→ 摆上屏不要钱,view 是留存状态,人回来就看得到([`arch/host.md`](../arch/host.md#attachment));该等的是**说话**,不是显示。
- **声音已经说过一次、人没反应** → 那是人看见了没兴趣,不是没送到;别追着重复([`reaction.md`](../../src/identity/reaction.md) 的"speaking first")。

## Open questions

- **非 view 交付物怎么确认送到。** 文件、外部动作(发出去的消息、改掉的配置)都没有"屏幕上出现过"这种可观测的落点。要不要给它们各自的落点,还是接受这一路只靠引导。
- **`## On their screen` 的窗口(现 90 分钟)够不够。** 一件跨越几小时的活,做完时最早那次上屏可能已经滚出窗口——目前会读成"没送到",宁可多提醒一次。
